# واصل — تطبيق توصيل الطلبات

**كل اللي تحتاجه... يوصلك** 🛵

تطبيق موبايل (أندرويد / iOS / ويب) لتوصيل الطلبات من المطاعم والبقالات والصيدليات للزبائن في ليبيا.
مبني بـ **React Native + Expo** مع واجهة عربية كاملة (RTL).

## ✨ المميزات الحالية

| القسم | التفاصيل |
|---|---|
| **تسجيل الدخول** | رقم هاتف ليبي (+218) → رمز تحقق OTP → الاسم. (في الوضع التجريبي الرمز هو `1234`) |
| **الرئيسية** | عنوان التوصيل الحالي، بحث، الأقسام (مطاعم، بقالة، صيدليات، حلويات، مخابز، قهوة، هدايا)، بانر عروض، مختارات واصل، المتاجر القريبة |
| **المتجر** | معلومات المتجر (تقييم، وقت التوصيل، الرسوم، أقل طلب)، القائمة مقسّمة حسب الأقسام مع تنقّل سريع، الأكثر طلباً، إضافة سريعة للسلة |
| **المنتج** | خيارات (حجم، إضافات) إجبارية/اختيارية، ملاحظات للمتجر، الكمية، حساب السعر لحظياً |
| **السلة** | تعديل الكميات، أكواد خصم (`WASEL` توصيل مجاني، `WASEL10` خصم 10%، `TRIPOLI5` خصم 5 د.ل)، التحقق من أقل قيمة طلب، منع خلط متاجر مختلفة |
| **إتمام الطلب** | اختيار عنوان التوصيل، طرق الدفع (كاش، سداد، موبي كاش، بطاقة — قريباً)، ملاحظات للسائق، ملخص كامل |
| **تتبع الطلب** | خط زمني للحالات (بانتظار التأكيد → تم التأكيد → جاري التحضير → في الطريق → تم التوصيل)، بيانات السائق مع زر اتصال، الوقت المتبقي، إلغاء الطلب (قبل التحضير)، التقييم، إعادة الطلب |
| **طلباتي** | الطلبات الحالية والسابقة مع شارات الحالة |
| **العناوين** | إضافة/تعديل/حذف عناوين، مناطق طرابلس جاهزة، عنوان افتراضي |
| **حسابي** | تعديل البيانات، العناوين، الإعدادات، تسجيل الخروج |
| **البحث** | بحث فوري في المتاجر والمنتجات مع عمليات البحث الأخيرة والأكثر بحثاً |

> 🧪 **وضع العرض (Mock Mode):** بدون باك إند، التطبيق يعمل ببيانات تجريبية محلية (15 متجر، +70 منتج)
> ويحاكي تقدّم الطلب تلقائياً كل بضع ثوانٍ حتى تقدر تجرّب التتبع كاملاً.

## 🚀 التشغيل

```bash
# 1) تثبيت الاعتماديات
npm install

# 2) التشغيل
npm start          # يفتح Expo Dev Tools — امسح الـ QR من تطبيق Expo Go
npm run android    # محاكي/جهاز أندرويد
npm run ios        # محاكي iOS (يحتاج macOS)
npm run web        # نسخة الويب في المتصفح
```

> ⚠️ **ملاحظة RTL على Expo Go:** أول مرة يفتح فيها التطبيق قد يظهر الاتجاه من اليسار لليمين.
> أغلق التطبيق وافتحه مرة ثانية ليُطبَّق الاتجاه العربي (هذا سلوك `I18nManager.forceRTL` ولا يحدث في البناء النهائي).

### أوامر أخرى

```bash
npm run typecheck   # فحص الأنواع TypeScript
npm run lint        # ESLint
npm run build:web   # تصدير نسخة ويب ثابتة في مجلد dist/
```

### متغيرات البيئة

انسخ `.env.example` إلى `.env` وعدّل القيم:

| المتغير | الوصف |
|---|---|
| `EXPO_PUBLIC_API_URL` | عنوان الباك إند. اتركه فارغاً لاستخدام البيانات التجريبية |
| `EXPO_PUBLIC_API_TIMEOUT_MS` | مهلة طلبات الشبكة (افتراضي 15000) |
| `EXPO_PUBLIC_SIMULATE_ORDERS` | `true` لمحاكاة تقدّم الطلبات محلياً |

## 🔌 ربط الباك إند

كل الشاشات تتعامل مع `src/services/api.ts` فقط. عند ضبط `EXPO_PUBLIC_API_URL` يتحوّل التطبيق تلقائياً من البيانات التجريبية إلى الـ REST API التالي (JSON):

| الطريقة | المسار | الوصف |
|---|---|---|
| `GET` | `/categories` | قائمة الأقسام |
| `GET` | `/stores?category=` | المتاجر (مع فلتر اختياري) |
| `GET` | `/stores/:id` | تفاصيل متجر |
| `GET` | `/stores/:id/products` | منتجات المتجر |
| `GET` | `/search?q=` | بحث → `{ stores, products }` |
| `GET` | `/payment-methods` | طرق الدفع المتاحة |
| `GET` | `/promos/:code` | التحقق من كود خصم |
| `POST` | `/auth/otp/send` | `{ phone }` → إرسال رمز |
| `POST` | `/auth/otp/verify` | `{ phone, code }` → `{ ok, user }` |
| `PUT` | `/me` | تحديث بيانات المستخدم |
| `POST` | `/orders` | إنشاء طلب → كائن `Order` |

أشكال الكائنات موجودة في `src/types/index.ts` (`Store`, `Product`, `Order`, `Address`, ...).
